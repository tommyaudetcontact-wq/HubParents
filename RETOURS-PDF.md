La construction montre les modèles de mobilier et les sols du jeu directement du dessus. Quatre poignées blanches redimensionnent les côtés des pièces. Les meubles exclus par une réduction ou une suppression reviennent dans l’inventaire ; leurs achats et finitions restent conservés. Annuler/rétablir restaure aussi les placements.

Le fantôme de placement devient vert ou rouge. Les commandes flottantes suivent le meuble : ✕ annule, ✓ installe, ↻ tourne de 45°, ✥ se maintient et se glisse pour déplacer. Le placement par toucher reste disponible. « Essayer dans ma maison avant d’acheter » permet de placer un aperçu sans débit : ✕ abandonne, ✓ achète puis enregistre le placement. En cas de sauvegarde du placement refusée après achat, le meuble reste possédé et peut être replacé sans le racheter.

Les besoins du personnage choisi apparaissent sous forme de six petites tuiles colorées, avec le détail accessible. Les modes passent par la navigation basse Vie / Maison / Personnage / Plus. La boutique de style ajoute le personnage en aperçu, le bouton Essayer et le filtre Tout / Déjà possédé / Pas encore acheté. Essayer ne change ni l’apparence enregistrée ni le solde.
